# 用 iOS 捷徑把 Apple 健康資料上傳到 Dashboard

網頁讀不到 Apple 健康，所以由「捷徑」每天讀取當日彙總，POST 到同步後端。後端以日期為鍵合併更新，同一天重複上傳不會重複。

## 後端接收的欄位
POST 到同步網址，JSON 內容：

| 欄位 | 說明 | 健康 App 的類型 |
|---|---|---|
| `token` | 同步金鑰（必填） | – |
| `kind` | 固定填 `health`（必填） | – |
| `date` | `yyyy-MM-dd`，省略則為今天 | – |
| `steps` | 步數 | 步數 |
| `exercise_min` | 運動分鐘 | 運動時間 |
| `active_kcal` | 活動消耗 | 活動能量 |
| `distance_km` | 距離（公里） | 步行＋跑步距離 |
| `diet_kcal` | 攝取熱量 | 膳食能量 |
| `protein_g` / `carbs_g` / `fat_g` | 三大營養素（克） | 蛋白質／碳水化合物／總脂肪 |
| `water_ml` | 喝水（毫升） | 水 |
| `sleep_h` | 睡眠（小時） | 睡眠（選填） |
| `weight_kg` | 體重（公斤） | 體重（選填） |

數值可帶單位或千分位（例如 `8,432`、`386.5 kcal`），後端只取數字。沒有的欄位可以不送。

## 建立捷徑「上傳健康資料」
每個要上傳的項目重複下面兩個動作（先做 2–3 項確認能通，再補齊）：

1. **尋找健康樣本**：類型選該項目（例：步數）；加入篩選條件「開始日期」「是今天」。
2. **計算統計資料**：運算選「總和」，輸入為上一步的健康樣本。建議長按這個結果「重新命名」（例：步數合計），後面比較好選。

最後加：

3. **格式化日期**：日期＝目前日期；格式選「自訂」，填 `yyyy-MM-dd`。
4. **取得 URL 內容**：
   - URL：你的同步網址（`https://script.google.com/macros/s/…/exec`）
   - 方法：POST
   - 要求本文：JSON
   - 加入欄位（類型皆選「文字」）：`token`＝你的金鑰、`kind`＝`health`、`date`＝格式化的日期、`steps`＝步數合計…（依上表逐一加入）
5. （選用）**顯示結果**：顯示上一步的回應。成功會看到 `{"ok":true,…}`；`bad token` 代表金鑰錯誤。

不同 iOS 版本的動作名稱可能略有出入；找不到時用搜尋列找「健康」「統計」「URL」。

## 每天自動執行
捷徑 App →「自動化」→ 新增 →「特定時間」（建議晚上手機還在使用的時間，例如 22:30）→ 每天 → 執行捷徑「上傳健康資料」→ 選「立即執行」（關閉執行前詢問）。

手機鎖定時健康資料是加密的，排在通常解鎖使用手機的時間較穩；也可以隨時手動執行。

## 注意
- 金鑰會以明文存在捷徑裡，請勿分享這個捷徑。
- 飲食數字要有 App 寫進 Apple 健康才會有（例如 FatSecret）。只選一個 App 寫入飲食，避免重複計算。
- 傳到健康的是數字（熱量、營養素），沒有餐點名稱。
