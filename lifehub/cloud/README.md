# 部署雲端同步（約 5 分鐘，需用你的 Google 帳號）

1. 到 https://sheets.google.com 建立空白試算表，命名「LifeHub 資料」。
2. 選單 **擴充功能 → Apps Script**，把 `Code.gs` 內容整份貼上取代預設程式，儲存。
3. 左側 **專案設定 → 指令碼屬性 → 新增**：名稱 `TOKEN`，值填一組自訂長密碼（這就是同步金鑰）。
4. 右上 **部署 → 新增部署作業 → 類型：網頁應用程式**
   - 執行身分：**我**
   - 誰可以存取：**所有人**（靠 TOKEN 保護；沒有金鑰讀不到任何資料）
   - 部署後複製「網頁應用程式網址」（`https://script.google.com/macros/s/.../exec`）。
5. 手機與電腦開啟 LifeHub → 點右上角 ● → 貼上網址與金鑰。
6. 之後修改 `Code.gs` 需「管理部署作業 → 編輯 → 新版本」才會生效。

注意：金鑰會出現在請求網址中，請設定夠長的隨機字串，勿分享網址給他人。
