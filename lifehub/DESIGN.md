# LifeHub 設計方向（草案 v0.2）

## 使用者輪廓 → 設計原則
| 特質 | 設計對應 |
|---|---|
| INTJ：系統化、長期策略、討厭雜訊 | 資訊密度高但層級清楚；每頁只有一個主要動作；預設收合細節；週／月「策略回顧」是一等公民 |
| 天秤：重視和諧、對稱、美感 | 對稱均衡的版面、充足留白、克制的配色、生活平衡輪（工作／健康／財務／學習／關係／藝術） |
| 藝術管理：策展思維 | 「美術館／編輯式」風格：襯線標題、細線分隔、卡片像展籤；內容像展品被好好陳列 |
| 董秘／副董特助：精準、時程、利害關係人、保密 | 日程與待追蹤（Waiting-for）、會議準備包、人脈與偏好紀錄、決策紀錄；資料只在自己的 Google 帳號內 |
| 八字（尚未納入） | 若提供日主／喜用神，可據此微調主色；目前以通用的沉穩配色為基礎 |

## 視覺
- **配色（淺色）**：紙白 `#F6F3EE`、墨黑 `#1F2430`、主色靛藍 `#2F3E5C`（策略／專注）、玫瑰灰 `#C9A9A6`（天秤／柔和）、鼠尾草綠 `#8FA58A`（完成／健康）、細金線 `#B08D57`（重點、分隔、徽章）。
- **深色**：墨底 `#14171F`、同組強調色降低飽和度。
- **字型**：標題襯線（Noto Serif TC / Cormorant）、內文黑體（Noto Sans TC / Inter）、數字等寬。
- **元件語彙**：1px 細線卡片、小型大寫標籤、左側細色條表示專案健康度（綠／金／玫瑰紅）、圖示用細線風格。
- 參考：Notion 美感模板（2–4 色一致用、圖示統一、用折疊保持畫面乾淨）、Trello 看板、Asana 列表／時間軸多視圖。

## 兩大骨幹
### A. 原子習慣（身分 → 系統 → 回顧）
- **身分宣言**置頂：「我是一個＿＿的人」，每個習慣綁一個身分；每次完成 = 為身分投一票（累計票數）。
- 每個習慣有四大法則欄位：提示（明顯）、渴望（吸引：誘惑綁定）、反應（簡單：2 分鐘版本）、獎勵（滿足）；另有「習慣堆疊」（做完 X 之後做 Y）、環境設計備註。
- 追蹤：週格＋連續天數＋「不連續失敗兩次」提醒；失敗不罰，顯示「回到軌道」。
- 每週回顧：哪些票投得多？哪個身分在弱化？

### B. 專案管理（PMBOK 第八版）
- **7 個績效域**作為每個專案的健康儀表：治理、範疇、時程、財務、利害關係人、資源、風險（各給綠／黃／紅＋一行註記）。
- **6 項原則**作為專案檢查清單（整體觀、品質內建、聚焦價值、永續、當責領導、賦能文化），在階段結束與結案時回顧。
- 專案頁：憲章（目標／成功標準／範疇邊界）、**RAID 紀錄**（風險／假設／議題／決策）、利害關係人登錄冊、里程碑、經驗教訓。
- 視圖：看板（Trello 式）、列表（Asana 式）、時間軸；同一份資料可切換。

## 各主題的邏輯與資料
| 主題 | 核心邏輯 | 主要欄位 |
|---|---|---|
| 習慣 | 身分投票、四大法則 | 身分、提示、2 分鐘版、堆疊、連續天、投票數 |
| 專案 | PMBOK 績效域＋RAID | 憲章、域狀態、風險、決策、利害關係人、里程碑 |
| 子彈筆記 | 快速記錄→每日／每月回顧→移轉 | 符號、狀態、日期、所屬專案／習慣 |
| 運動 | 週目標、恢復、趨勢（日後接 Apple 健康） | 類型、時間、強度、感受 |
| 財務 | 預算、分類、淨值趨勢、固定支出 | 金額、類別、帳戶、定期 |
| 知識 | 筆記雙向連結、閱讀→摘要→行動 | 標題、標籤、來源、行動項目 |
| 閱讀 | 進度、心得、「我會怎麼用」 | 狀態、頁數、評分、行動 |

## 導覽（手機 5 分頁；桌機左側邊欄）
今日｜專案（個人專案）｜習慣｜生活（運動／財務）｜知識（筆記／閱讀）
- **今日**：身分宣言、今日 3 件最重要的事、習慣打卡。
- **每週回顧**（週日）：平衡輪、習慣投票、專案健康、下週三件事。

## 實作順序（建議，皆走分支＋PR）
1. 換視覺系統（配色、字型、卡片）＋ 導覽重整
2. 習慣模組（身分＋四大法則）
3. 專案模組（7 域＋RAID＋看板／列表）
4. 每週回顧與平衡輪
5. 運動／財務／知識升級各自邏輯；之後再接 Apple 健康、OtterLife
